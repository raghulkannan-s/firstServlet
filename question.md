“Can You Survive ZSgs?”
Design a quiz kinda interface in HTML with the following params.


Parameters:

    1. cups of tea or coffee per day
    2. sleep hours
    3. assignment backlog count
    4. number of problems solved in LeetCode
    5. number of problems solved in the last assessment 

Write your own algorithm or formula to calculate the survival percentage in a servlet according to the parameters. 
And show a response interestingly in UI.
